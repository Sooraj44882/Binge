## what i made till now 
here are all the components i built for this project:
- **Intro / Login Page:** a starting page that asks for your name and email before letting you in.


- **Sidebar:** a left-side navigation bar that expands when you hover over it, complete with standard streaming icons (search, home, series, settings).


- **Navbar** the top navigation menu for your profile and quick links.
- **Hero:** the massive spotlight movie banner at the very top of the home page with a faded gradient background.
- **Row:** horizontal scrolling movie lists. 
- **Modal:** when you click a movie in the row, pop-up window appears over the website showing the movie's title, description and buttons.
- **Settings:** a dedicated page that where subscription,theme ,autplay and many other setting stuff will be there.


## tech stack & how it was made

- **react (vite):** the core framework.
- **tailwind css:** for all the styling (used to make the slick dark mode, gradients and hover effects).
- **react-router-dom:** handles the routing (like hiding the sidebar on the intro page but showing it everywhere else).
- **react-icons:** for svg icons in the sidebar and modals.
